❓ How to use Groove

Everything in one place — from first bulb to full light show.
1 · Add your lights
Tap ➕ Add → 🔍 Scan to find bulbs on your WiFi, or type a Device ID + IP manually. A brand-new bulb must first be joined to your WiFi via the Govee app.
2 · Arrange the canvas
Drag bulbs to match where they really are. Tap 🔗 Set order, then click bulbs in the order you want effects to travel (1→2→3…), then tap Done. Effects and chases follow this order.
3 · Choose colors
The palette is your color set — every effect uses it. Tap + color to add a random color, tap a swatch to delete it.
4 · Run an effect
Pick one of 34 effects from the dropdown, set the Step speed slider, tap Start. Tap Stop to end it. The bulbs on the canvas glow in their real current color.
🎉 Party · 🎄 Christmas
Auto-rotates random (or Christmas) effects and colors every ~20 seconds. Runs on the server, so it keeps going even if you close this page. Tap the button again to stop.
5 · Click a bulb
Opens its controls: change color, on/off, brightness — or type a new name and press Enter to rename it.
💾 Scenes
Save the current colors as a named scene and recall it in one tap. Each scene gets a trigger URL — bookmark it, or use it in Siri Shortcuts / Stream Deck.
⏰ Schedule
Run any effect at a set time. The 🌇 Auto toggle turns lights on at sunset and off at sunrise — just enter your ZIP code.
✨ Presets · 🎲 Surprise
Presets are one-tap saved setups. Surprise instantly picks a random effect with random colors.
